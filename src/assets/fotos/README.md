# Fotos reais da loja

Jogue as fotos da Grand Pet aqui (`.jpg`, `.jpeg`, `.png` ou `.webp`).
A seção "A Grand Pet no Instagram" na home renderiza sozinha o que estiver
nesta pasta — nenhuma foto aqui, seção some. Não precisa mexer no código.

Convenções:

- **Ordem** = ordem alfabética do nome do arquivo. Use prefixo numérico:
  `01-banho-tosa.jpg`, `02-boutique-cama.jpg`, `03-roupinha.jpg`, `04-loja.jpg`.
- **Texto alternativo (SEO + acessibilidade)** = o próprio nome do arquivo, sem
  a extensão e com os hífens virando espaços. Ou seja `01-banho-e-tosa-yorkshire.jpg`
  vira o alt "banho e tosa yorkshire". Por isso vale nomear descritivo.
- **Formato**: quadradas ficam melhores (o grid recorta pro centro). ~1080×1080px.
  Se puder, salve em `.webp` — pesa menos.
